# Student Grade Management System

This Python program is designed to manage student grades by calculating letter grades based on exam scores. Users can view, add, and save grades, which are stored in external text files.

---

## Features

1. **Read Grades**  
   Displays the list of student grades along with their calculated letter grades.

2. **Add Grades**  
   Allows users to input a student's name and their exam scores, which are then saved in the `sınav_notları.txt` file.

3. **Save Final Grades**  
   Converts numerical grades into letter grades and saves the results to a new file called `sonuçlar.txt`.

4. **Exit**  
   Ends the program.

---

## File Structure

- `sınav_notları.txt`: Stores student names and their raw scores in the format:  
Onur Tezel:86,79,96
- `sonuçlar.txt`: Stores student names and their letter grades in the format:
Onur Tezel: BA
